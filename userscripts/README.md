# Userscripts

Scripts that add features to websites or fix things on them. Each one has its own folder with a README covering what it does, how to install it and its settings.

| Script | Site | What it does |
|---|---|---|
| [Amazon Xmas Export](amazon-xmas-export/) | amazon.com | Copies chosen items from an order, with tax added, as rows to paste into a Christmas shopping Google Sheet. |
| [Kroger Improvements](kroger-improvements/) | kroger.com | Speeds up the site by stopping analytics, survey and monitoring scripts, and hides sponsored ads and products. |
| [Reddit Video Downloader](reddit-video-downloader/) | reddit.com | One-click download of Reddit-hosted videos, with sound, on old and new Reddit. |
| [YouTube Declutter](youtube-declutter/) | youtube.com | Hides unused sidebar sections, banners and shelves, expands the subscriptions list, and opens Shorts in the normal player. |
| [YouTube yt-dlp Download](youtube-yt-dlp-download/) | youtube.com | Adds a download button under videos that hands the video to yt-dlp on your PC. Windows only. |

## Install

1. Install a userscript manager: [Violentmonkey](https://violentmonkey.github.io/) or [Tampermonkey](https://www.tampermonkey.net/).
2. Open the script's `.user.js` link from its README. The manager offers to install it and keeps it up to date.
