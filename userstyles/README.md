# Userstyles

CSS that changes how websites look, mostly by hiding clutter. Each style applies only to the site it targets.

| Style | Site | What it does |
|---|---|---|
| [Fandom Declutter](https://raw.githubusercontent.com/jcackowski/tools/main/userstyles/fandom-declutter.user.css) | fandom.com | Hides ads, the featured video, and Fandom UI unrelated to the page's subject. |
| [YouTube Declutter](https://raw.githubusercontent.com/jcackowski/tools/main/userstyles/youtube-declutter.user.css) | youtube.com | Hides extra sidebar sections, the footer, the Create button, game shelves, the side-panel dimming and channel banners. |

## Install

1. Install [Stylus](https://add0n.com/stylus.html).
2. Click a style's name above. Stylus opens an install page and keeps the style up to date.

The [YouTube Declutter userscript](../userscripts/youtube-declutter/) covers everything this style hides, and also expands the subscriptions list and redirects Shorts. You only need one of the two.
